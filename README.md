# Chanchi

App Android de alquileres para Argentina. La interfaz (HTML) vive en `app/src/main/assets/www`, el código nativo en `app/src/main/java`.

- Cada push a `main` compila y publica un APK en **Releases**.
- La app revisa Releases al abrirse y ofrece actualizarse sola.
- `web-src/` tiene la plantilla original de la interfaz.
